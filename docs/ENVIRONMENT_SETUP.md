## Инструменты и команды

Godot 4.5.1 установлен из официального архива с проверкой SHA-512. Для снимков используется локально установленный Xvfb и программный OpenGL Mesa. Открытый порт и браузер не требуются. Аудиовывод облачной среды заменяется Dummy; фактическое звучание не проверено.

```bash
bash /workspace/.cloud-tools/onboarding-install.sh
source /workspace/.cloud-tools/godot-env.sh
cd /workspace/Game-AI-/game
shashlik-godot --headless --audio-driver Dummy -- --self-test
shashlik-godot --headless --audio-driver Dummy --script res://tests/contact_audit_06.gd
shashlik-godot --headless --audio-driver Dummy --script res://tests/hero_validation.gd
```

Новый набор снимков, с отдельным каталогом на каждый прогон:

```bash
source /workspace/.cloud-tools/godot-env.sh
capture_dir=$(mktemp -d /workspace/shashlik-validation/capture.XXXXXX)
SHASHLIK_CAPTURE_DIR="$capture_dir" shashlik-render --script res://tests/review_current.gd
```

`shashlik-render` запускает собственный Xvfb для каждой команды и завершает его при выходе. Процессы не требуется переносить между задачами. Обычный запуск игры: `shashlik-render`; выход штатный либо завершение запущенного нами процесса. Визуальный запуск с захватом кадров не означает ручного прохождения на Windows.

Python для генераторов: `/workspace/.cloud-tools/authoring-venv/bin/python`; точные версии зависимостей записаны в `/workspace/.cloud-tools/authoring-requirements.txt`. Генератор собаки выполнен в отдельной копии; оригинальная игровая модель не перезаписывалась. Исторический `build_casual_assets.py` требует старых ресурсов Superhero, отсутствующих в Graphics 06; для обычного запуска он не нужен.

Встроенный Blender имеет версию 4.3.2. Исходник Alina_Animated.blend прочитан: 8 объектов, 1 скелет, 9 действий. Blender предупреждает, что файл сохранён более новой версией 4.5. До редактирования и пересохранения исходных .blend установить совместимый Blender 4.5.3 или новее и проверить экспорт в отдельной копии. Исходный .blend не изменён.

## Границы проверки и дальнейшая работа

Успех автоматических тестов не доказывает естественность поз и качество графики. На просмотренных кадрах собака остаётся условной по силуэту и деталям, лица имеют резкие переходы освещения, земля и растительность выглядят повторяющимися. Это исходные наблюдения, не исправленные дефекты. Нужны отдельная оценка движений, переходов и контактов и дальнейшая переработка по полному ТЗ. Тест контактов сообщает дрейф опорных лап до примерно 11 мм на кадр на высокой скорости и не проверяет его отдельным утверждением: PASS не означает отсутствия скольжения.

Windows-сборка, ручное прохождение, звук, производительность на видеокарте пользователя и восстановление в новой опубликованной задаче не проверены. Большое графическое задание этим этапом не завершено. Отчёт по фрилансу не использовался для разработки игры. Текущая работа ограничена восстановлением и настройкой; логика, модели и текстуры не редактировались.
