# Итерация 11: исправление сложенной шеи и её привязки

22 октября 2026 года. По прямому запросу «Исправляй», после диагноза 10. Исправление геометрии и привязки выполнено, окончательные кадры просмотрены; новая архивная точка проверена отдельно. Предыдущие контрольные точки сохранены.

Создан отдельный `AlinaNeck11.glb` из исходного, несамопересекающегося бюста и сохранённых материалов/мимики 09. Прежний сдвиг по маске глубины удалён. Подгонка теперь переводит полные горизонтальные сечения с плавным затуханием по высоте; этот шаг сохраняет порядок точек. Высокий косой нижний край исходного бюста дополнительно продлён под ворот: при осмотре сзади без волос он больше не выступает как видимый срез. Граница остаётся открытой под одеждой; это не новая полностью замкнутая модель тела.

Заново распределены веса груди/шеи/головы широкими переходами по высоте. Скелет из 67 костей и все 63 канала мимики сохранены, UV и топология головы прежние. Поверхность лица выше области шеи, волосы, глаза и рот не изменены; дельты мимики сохранены с погрешностью float. Runtime заменяет только голову/шею после overlay 09. Тело/одежда, игровые роли и правила этим ресурсом не меняются.

В гитарной позе шея теперь продолжает ориентацию грудной клетки; прежняя противоходная постановка, концентрировавшая наклон в голове, заменена плавным распределением. Нейтральный взгляд вниз уменьшен с 0,40 до 0,28 рад. Переключатель `neck_revision=false` оставляет прежнюю геометрию и постановку для сравнения.

Экспортный аудит в рабочей копии: ноль самопересечений шеи при проверке выбранных треугольников против всей кожи головы; раньше в локальной зоне находилось 83 пары. Максимальный скачок веса Head в передней зоне уменьшен с 0,416 до 0,102. Нижняя граница теперь находится на высоте 1,2375–1,2430 м под одеждой. Числа относятся к координатам/сетке модели, не нормам человеческой анатомии. Проверка героя новой Алины пройдена. Проверены 11 живых состояний/направлений взгляда: в выбранной зоне шеи пересечений с остальной кожей не найдено, rest совпадает с реальной привязкой. Круговые кадры и полная архивная проверка готовятся.

В промежуточных пробах проверены передняя, обе боковые и задняя проекции без волос. Складка под челюстью устранена; найденный при этом задний срез бюста также исправлен. Окончательная визуальная оценка будет сделана по сопоставимым кадрам после фиксации исходников. Общая анатомия тела, одежда/кисти/локти, движение и качество Sons of the Forest этим исправлением не объявляются завершёнными.

Генератор: `game/tools/authoring/build_alina_neck.py`; независимый аудит: `tools/audit_alina_neck.py`; живые позы: `game/tests/neck_deformation.gd` и `tools/verify_neck_deformation.py`; реальные кадры: `game/tests/neck_review.gd`. Новые проверки используют фактический GLB, bind-матрицы, веса, лицевые morph-дельты и экспортированные из работающего Godot позы костей. Совпадение rest проверяется отдельно, чтобы не принять ошибку координат за успешную деформацию.
