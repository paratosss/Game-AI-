# «Шашлык у пруда»: рабочая переработка Graphics 06

Это исходный Godot-проект для ПК. Большое ТЗ по графике выполняется; контрольная точка не означает полного завершения визуальной работы. Итоговое состояние и ограничения см. в WORK_IN_PROGRESS_RU.md и приложенном журнале.

## Запуск

1. Распакуйте архив целиком.
2. В Godot 4.5.1 выберите «Импорт» и файл project.godot из папки shashlik-godot-v06.
3. Дождитесь импорта ресурсов. Откройте проект и нажмите F5.

Отдельного Windows EXE в этом архиве нет. Для открытия редактора в Windows можно перетащить Godot.exe на START_WINDOWS.bat. Старую папку Demo 04.3 открывать для просмотра этой версии не нужно.

## Управление

WASD — ходьба; мышь — обзор; Space — прыжок.
E — взять предмет, добавить продукт на шампур, нанести маринад, положить шампур в подсвеченное место мангала или подать еду гостю.
R — перевернуть шампур в руках или на мангале под прицелом.
Q — отпустить; G — бросить. Опахало: E — взять, ЛКМ — махать рядом с углями.
F1 — управление; M — звук; F5 — новая поляна. Esc освобождает курсор; клик возвращает управление. Освобождение курсора не останавливает готовку.

## Сохранённая механика

Три места мангала, шесть продуктов на шампуре, пять видов еды и два маринада. Прожарка считается отдельно для двух сторон. Заказы приходят постепенно; одновременно до двух заказов. Люди реагируют на сырое, сгоревшее, грязное и замены; Арториас принимает плохую еду. Гости возвращаются к занятиям. Мяч, гитара, лай, музыка и опахало сохранены.

Правила приготовления и начисления очков находятся в scripts/rules.gd и не изменялись. Закупки, экономика, сохранение игрового прогресса и матч по правилам волейбола в эту работу не добавлялись.
